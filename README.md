# Amora Intimates: Pure Elegance

Crie um site completo, moderno, sofisticado, feminino e altamente responsivo para a marca de lingerie "Amora Intimates".

IMPORTANTE: este projeto NÃO é um e-commerce.

Não criar:

- Carrinho

- Checkout

- Pagamento online

- Login

- Cadastro de clientes

- Área do cliente

- Sistema de pedidos

- Gateway de pagamento

O site deve funcionar como:

MARCA + CATÁLOGO DE PRODUTOS + EXPERIÊNCIA EDITORIAL + GERAÇÃO DE LEADS PELO WHATSAPP.

O objetivo principal é fazer a visitante se apaixonar pela marca e pelas peças e, em seguida, iniciar uma conversa pelo WhatsApp para consultar disponibilidade, tamanhos, valores e realizar a compra com uma atendente.

==================================================

CONCEITO PRINCIPAL

==================================================

A Amora Intimates deve parecer uma marca real de lingerie premium, não um template de loja virtual.

A estética deve combinar:

- Editorial de moda

- Minimalismo

- Luxo discreto

- Feminilidade

- Sensualidade sofisticada

- Fotografia de campanha

- Tipografia elegante

- Muito espaço negativo

- Interface extremamente limpa

Imagine uma mistura entre:

"revista de moda + campanha de lingerie + catálogo premium + landing page de alta conversão".

O resultado precisa parecer profissional o suficiente para uma marca estabelecida.

NÃO criar aparência de:

- Marketplace

- Loja virtual genérica

- Template SaaS

- Site barato

- Catálogo excessivamente cheio

- Página com muitos cards e bordas

A fotografia e a tipografia devem ser protagonistas.
